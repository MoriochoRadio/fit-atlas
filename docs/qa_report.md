## 반영한 QA 수정

운동 라이브러리는 이후 확장을 거쳐 **8개 범주·79개 항목**을 제공하며, 각 항목에 세 가지 이상의 효과 태그와 단계형 자세 단서를 포함합니다. 대표 운동에는 CSS 실루엣의 단계형 시각 가이드를, 목표별 화면에는 근력·심폐·체중 관리·전신 건강을 위한 보수적 4주 템플릿을 추가했습니다. 또한 에너지·수면·스트레스·통증을 브라우저에만 저장하는 일일 체크인을 추가해, 통증 신호를 우선하고 준비도에 따라 회복·가벼운 조정·계획 진행을 안내하도록 했습니다. 가용 시간·운동 환경·목표를 조합하는 단일 세션 설계 도구도 같은 체크인 결과를 반영해 준비·주요 움직임·마무리 순서의 정적 안내를 제시합니다. 운동 기록 모달에는 **날짜 선택**을 넣어 과거 기록도 캘린더와 주간 분석에 반영할 수 있게 했습니다. 검색 필터·로컬 저장·백업 오류·회복·웰니스·개인화 안전 원칙 테스트도 추가했습니다.

이번 추가 확장에서는 1280px 전체 화면과 375px 모바일 너비에서 새 세션 설계 구조를 점검했습니다. 모바일 헤더·카드의 기본 대비와 선택지의 줄바꿈은 유지되었고, 최신 카탈로그 수는 **79개 운동**으로 표시되었습니다. `pnpm check`, 12개 테스트 파일의 27개 테스트, 정적 프로덕션 빌드를 모두 통과했습니다.

주간 계획 확장에서는 같은 데스크톱·모바일 폭에서 완료 체크 버튼, 목표 전환 버튼, 설계 세션 추가 버튼과 세션 목록의 단일 열 전환을 확인했습니다. 현재 시각 점검 범위에서는 섹션 간 배경 대비와 모바일 카드의 순차적 쌓임이 유지되었습니다. `pnpm check`, 13개 테스트 파일의 31개 테스트, 정적 프로덕션 빌드를 모두 통과했습니다.

계획-기록 연결 확장에서는 주간 카드의 기록 시작 버튼, 완료·기록 연결 상태 문구, 요약 보조 문구를 1280px 데스크톱과 375px 모바일 전체 화면에서 점검했습니다. 현재 구성에서는 버튼과 카드 내용이 기존 주간 패널의 대비·단일 열 반응형 흐름을 유지합니다. `pnpm check`, 13개 테스트 파일의 32개 테스트, 정적 프로덕션 빌드를 모두 통과했습니다.

운동 카탈로그 확장에서는 1280px 데스크톱과 375px 모바일 전체 화면에서 새 **파워·민첩성** 카테고리와 확장된 운동 탐색 영역을 점검했습니다. 추가 카테고리는 기존 가로 필터 흐름에 포함되며, 모바일에서도 탐색 카드의 단일 열 흐름과 섹션 대비가 유지되었습니다. `pnpm check`, 13개 테스트 파일의 33개 테스트, 정적 프로덕션 빌드를 모두 통과했습니다.

최신 작업 환경을 동기화한 뒤 타입 검사·테스트·정적 빌드를 다시 실행해 외부 수정으로 인한 회귀가 없음을 확인했습니다. 이번 확장에서는 당기기·런지·파워·민첩성·발목 움직임의 3단계 CSS 자세 가이드와 부위별 **운동 전 준비·운동 후 회복·부하 재개** 카드를 추가했습니다. 또한 수면·카페인·운동 시간의 개인 반응을 기록하는 웰니스 카드를 보강했습니다. 1280px 데스크톱과 375px 모바일 전체 화면에서 회복·웰니스 카드의 대비와 모바일 단일 열 전환을 확인했습니다. 새 안내 컴포넌트는 실제 서버 마크업 테스트로도 확인했습니다. `pnpm check`, 14개 테스트 파일의 36개 테스트, 정적 프로덕션 빌드를 모두 통과했습니다.

원격 `main`에 병합된 배포·접근성 수정과 최신 콘텐츠 확장을 리베이스로 함께 통합했습니다. 충돌한 스타일 파일에서는 원격의 모바일 조작 대상 최소 크기 개선과 새 포즈·회복 단계 스타일을 모두 보존했으며, 통합 뒤 `pnpm check`, 14개 테스트 파일의 36개 테스트, 정적 빌드를 다시 통과했습니다.

## 의도된 정적 버전의 경계

이 버전은 개인·소수 사용자의 브라우저에서만 데이터를 관리하며 계정 동기화·실시간 공동 사용·원격 데이터 백업은 제공하지 않습니다. 콘텐츠는 근거 링크를 갖춘 교육용 큐레이션이며 의학적 진단이나 재활 치료 처방이 아닙니다.
