# 개인 수행 운동 대량 확장 근거 메모

CDC 성인 활동 안내는 유산소 활동과 주요 근육군을 다루는 근력 활동을 함께 고려하며, 활동량은 여러 짧은 구간으로 나누어 수행할 수 있다고 설명한다.[1] 카탈로그 확장에서는 개인 처방이 아니라, 낮은 강도·작은 가동 범위·한 변수씩의 점진적 조절·통증·어지러움·비정상적 숨참 시 중단이라는 보수적 일반 원칙을 유지한다.
