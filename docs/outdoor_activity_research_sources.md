# 야외 보행·트레킹 콘텐츠 조사 메모

NPS는 하이킹 전 경험·지형·고도·날씨·장비를 고려해 자신의 한계에 맞는 경로를 고르고, 동반자·여행 계획·비상 계획을 준비하도록 안내한다. 또한 보행 중 말하기가 가능한 속도를 일반적인 적정 속도의 한 단서로 제시하며, 물·간식을 준비하고 미끄러운 구간에서는 발밑을 확인하도록 권고한다.[1] 야외 활동 시 물을 갈증이 오기 전부터 자주 마시고, 이동 전 수분 계획을 세우라는 NPS 안내도 반영했다.[2]
