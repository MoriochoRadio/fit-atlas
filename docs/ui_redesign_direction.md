# Fit Atlas UI Redesign Direction

## 방향

이번 개편은 일반적인 카드형 피트니스 대시보드가 아니라, **운동 지도를 탐색하는 편집형 데이터 아틀라스**를 목표로 한다. 정보량은 유지하되 한 화면의 우선순위를 명확히 하고, 탐색·계획·기록·회복을 서로 다른 문서 페이지가 아니라 하나의 이동 경로로 보이게 한다.

| 요소 | 설계 결정 |
|---|---|
| 시각적 은유 | 좌표, 등고선, 경로, 측정 눈금으로 구성한 **움직임 아틀라스** |
| 색상 | 딥 잉크 그린, 웜 페이퍼, 산성 라임을 선택·진행·핵심 수치에 한정 사용하고, 코랄을 안전·중단 신호에 사용 |
| 타이포그래피 | 큰 한국어 편집형 제목, 모노스페이스 좌표·라벨, 읽기 쉬운 본문으로 세 계층 분리 |
| 정보 구조 | 히어로의 방향 제시 → 오늘의 계획 → 운동 탐색 → 회복·기록·웰니스의 순서로 재조직 |
| 표면·공간 | 얇은 규칙선, 넓은 여백, 중첩 패널, 작은 라벨을 사용하고 동일한 카드 반복을 줄임 |
| 모션 | 선택·진입·강조 순간에만 160–260ms의 `transform`·`opacity` 전환을 사용하며 reduced motion을 지원 |

## 사용자 흐름

초기 화면은 카탈로그 전체를 한꺼번에 보여 주는 대신 **오늘의 출발점**을 먼저 제안한다. 사용자는 목표와 컨디션을 확인하고 세션을 설계하거나, 선호 조건을 적용해 카탈로그 탐색으로 이동한다. 회복과 기록은 부차적인 탭이 아니라 현재 활동의 반응을 다시 다음 선택으로 돌려보내는 피드백 경로로 다룬다.

## 기능 보존 기준

전면 개편은 기존의 로컬 저장, 백업·가져오기, 카테고리·부위·목적·난이도·장비 필터, 즐겨찾기, 최근 본 운동, 세션 설계, 주간 계획, 기록 분석, 바디 맵, 회복 경로, 근거 범위 안내를 제거하거나 의미를 바꾸지 않는다. 페이지당 카탈로그 로딩은 유지하되 초기 노출 카드 수를 줄여 탐색의 시각적 피로를 낮춘다.

## 접근성 기준

명암 대비를 배경별로 보장하고, 선택 상태는 색상 외에 테두리·텍스트·`aria-pressed`로 드러낸다. 모든 버튼·입력은 모바일에서 충분한 터치 영역을 유지한다. 장식용 지도·그리드·원형 요소는 콘텐츠 의미를 대체하지 않으며, 모션 감소 환경에서는 비필수 전환을 제거한다.
