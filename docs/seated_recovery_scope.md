# 장시간 앉기 뒤 회복 루틴의 적용 범위

## 목적

이 기능은 장시간 같은 자세로 작업한 뒤 **환경을 확인하고, 자세를 바꾸고, 짧게 걷는 선택지**를 제시하는 일반 교육용 흐름이다. 통증의 원인을 진단하거나 치료하지 않으며, 운동 처방·의료 평가·작업장 위험성 평가를 대체하지 않는다.

| 구성 | 적용 방식 | 경계 |
|---|---|---|
| 5분 자리 리셋 | 환경 확인, 손·어깨의 작은 움직임, 짧은 보행, 반응 확인 | 강한 끝 범위 스트레칭·통증을 통과하는 동작을 제안하지 않음 |
| 10분 자리 회복·재시작 | 5분 흐름에 가벼운 체중 이동과 지지된 일어서기·걷기를 추가 | 땀을 내는 운동이나 부하 훈련이 목적이 아님 |
| 오늘의 조정 | 일일 체크인과 선택적 회복 맥락에 따라 범위·시간을 보수적으로 낮춤 | 통증 점수가 높은 경우 자가 진행을 보류 |

CDC는 "더 움직이고 덜 앉기"를 성인 일반 신체 활동 원칙으로 안내한다.[1] NIOSH는 작업 환경을 개인의 능력과 한계에 맞추는 인체공학적 설계를 설명하며, 부자연스러운 자세·반복 동작·작업의 강도·빈도가 불편과 부상 위험 요인이 될 수 있음을 제시한다.[2] Mayo Clinic의 작업 인체공학 안내는 같은 자세로 수시간 앉아 있지 말고, 자주 일어나 움직이며 손·손가락·팔을 가볍게 움직이는 방식을 소개한다.[3]

## 자가 진행을 멈출 신호

새로운 날카로운 통증, 저림·감각 변화, 갑작스러운 힘 빠짐, 보행 불안, 어지러움·비정상적 숨참, 외상 뒤 변형·붓기·열감, 또는 움직일수록 빠르게 악화되는 통증은 이 루틴의 적용 범위를 벗어난다. 이러한 경우 루틴을 반복하거나 운동 강도를 올리지 말고 필요한 평가를 우선한다.
