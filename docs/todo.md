# Fit Atlas 작업 목록

- [x] 의료 진단·치료를 대체하지 않는 운동·재활 콘텐츠 안전 고지와 위험 신호 안내를 마련한다.
- [x] 운동 처방 및 회복 가이드에서 인용할 공신력 있는 연구·가이드라인 출처 기준을 정한다.
- [x] 고급스럽고 일관된 반응형 디자인 시스템(색상, 서체, 간격, 모션)을 정의한다.
- [x] 운동 탐색, 해부도, 개인 프로그램, 기록, 분석, 회복, 웰니스로 이어지는 전역 내비게이션을 구현한다.
- [x] 운동 카테고리·부위·목적·난이도·장비 기준의 검색 및 필터링을 구현한다.
- [x] 운동별 올바른 자세, 타깃 근육, 효과, 준비물, 주의 사항, 연구 근거를 제공하는 백과사전 화면을 구현한다.
- [x] 클릭 가능한 신체 부위 시각화와 부위별 관련 운동 및 회복 가이드를 구현한다.
- [x] 연령·체중·성별·목표·경험 수준을 수집하는 프로필 및 개인화 프로그램 추천을 구현한다.
- [x] 운동 종목·세트·횟수·중량·시간·강도 입력과 저장을 구현한다.
- [x] 날짜별 운동 캘린더와 운동 이력을 구현한다.
- [x] 운동 볼륨·빈도·진행도 차트와 개인 최고 기록(PR) 추적을 구현한다.
- [x] 통증 부위별 스트레칭·폼롤러·마사지건의 안전한 회복 가이드를 구현한다.
- [x] 식단·영양·수면·사우나 활용을 다루는 웰니스 가이드 화면을 구현한다.
- [x] 데이터베이스 스키마, 서버 질의, 타입 안전 API 및 권한 보호를 구현한다.
- [x] 운동 데이터와 핵심 계산 로직에 대한 Vitest 테스트를 작성하고 실행한다.
- [x] 데스크톱·모바일 화면을 검토하고 접근성·시각 품질을 개선한다.
- [x] GitHub 원격 저장소에 소스와 문서를 반영한다.
- [x] 실제 인증 사용자 컨텍스트로 운동 기록을 저장·조회해 계정 기록의 서버 저장을 확인한다. (임시 인증 사용자·보호 API·DB 왕복 검증 완료)
- [x] 부위 전용 필터와 검색·목적·난이도·장비 필터의 조합 동작을 보강한다.
- [x] 연령·체중·성별·목표·경험 수준을 모두 반영하는 보수적 개인화 규칙과 저장 피드백을 구현한다.
- [x] 게스트·로그인 운동 기록 경로의 입력 검증과 저장 성공·실패 피드백을 구현한다.
- [x] 운동 볼륨·PR·주간 캘린더 집계 계산을 분리하고 Vitest로 검증한다.
- [x] 연령·체중·성별·경험 수준이 추천 운동·초기 강도·볼륨 규칙에 반영되는 개인화 로직과 테스트를 추가한다.
- [x] 성별만으로 운동 부하를 처방하지 않는 원칙을 유지하면서, 사용자가 선택적으로 제공하는 생애주기·컨디션 정보에 따라 안전한 추가 개인화 기준을 설계한다.
- [x] 실제 인증 사용자 컨텍스트로 선택적 안전 모드를 저장·조회하고 로그인·비로그인 상태 병합을 확인한다. (보호 API·DB 왕복 및 게스트·계정 프로필 병합 로직 검증 완료)
- [x] 임시 인증 컨텍스트에서 보호된 프로필·운동 기록 API의 실제 DB 저장·조회 왕복을 검증한다.
- [x] 관리형 데이터베이스 연결 복구 여부를 재점검하고 미적용 프로필 마이그레이션을 적용한다.
- [x] 사용자 승인 후 관리형 데이터베이스 연결과 `recoveryContext` 컬럼 적용 상태를 다시 확인한다.
- [x] 관리형 데이터베이스 연결을 복구하고 안전 모드 마이그레이션을 적용·확인한다.
- [x] 서버·DB·인증 의존성을 제거하고 브라우저 로컬 저장소 기반으로 전환한다.
- [x] 운동 기록·프로필·안전 모드의 로컬 저장·복원과 내보내기·가져오기를 구현한다.
- [x] 정적 호스팅에 맞는 빌드 설정과 GitHub Pages 배포 워크플로를 추가한다.
- [x] 불필요한 런타임 의존성을 정리하고 정적 빌드·모바일 사용성을 검증한다.
- [x] 메인 번들을 추가 분할해 500 kB 경고 없이 정적 빌드가 통과하도록 최적화한다.
- [x] 남은 클라이언트 의존성·코드의 실제 사용 여부와 번들 크기 변화를 문서화한다.
- [x] 최초 요구사항의 운동 백과사전·해부도·개인화·기록·분석·회복·웰니스 항목을 현재 구현과 대조한다.
- [x] 로컬 저장·백업 복원·검색 필터·개인화·기록 분석의 정상·오류 경로를 자동 검증한다.
- [x] 데스크톱·모바일 UI, 정적 빌드 및 GitHub Pages 워크플로를 재검증한다.
- [x] QA에서 발견한 누락 요구사항·오류를 수정하고 회귀 테스트한다.
- [x] 정적 운동 백과사전을 각 핵심 카테고리와 7개 신체 부위를 더 넓게 포괄하도록 확장한다.
- [x] 각 운동에 근력·체력·심폐·가동성 효과와 단계별 자세 단서를 명시적으로 보강한다.
- [x] 필터 조합과 로컬 기록·백업 복원·개인화 규칙의 경계 조건을 자동 테스트로 보강한다.
- [x] 운동 기록에 날짜 선택을 추가해 과거 이력과 날짜별 캘린더 분석을 직접 입력할 수 있게 한다.

- [x] 힘·심폐·가동성·균형·협응 목적과 장비·난이도·부위 필터 분류를 확장한다.
- [x] 폼롤러·마사지건·스트레칭·통증 위험 신호·수면·영양·열 노출 콘텐츠를 보강한다.

- [x] 유산소·근력·균형·가동성·협응의 더 다양한 종목과 장비 변형을 정적 백과사전에 추가한다.

- [x] 가용 시간·장비·목표를 기준으로 균형 잡힌 단일 세션을 제안하는 정적 설계 도구를 추가한다.
