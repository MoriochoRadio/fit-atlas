# Fit Atlas 최초 요구사항 재대조

마지막 재대조일: 2026-08-19. Fit Atlas는 서버·DB 없이 브라우저 `localStorage`와 JSON 백업을 사용하는 개인·소수 사용자용 정적 웹 앱으로 유지한다. 따라서 이 문서는 구현 여부뿐 아니라, 정적 앱과 일반 운동 교육 콘텐츠가 갖는 한계도 함께 기록한다.

## 이번 우선 개발

초기 요구사항 중 가장 큰 품질 공백은 운동 링크가 무엇을 뒷받침하는지 불명확했던 점이었다. 상세 카드의 **근거 적용 범위** 패널은 운동명·장비·주동근을 확인하는 원천, 일반 활동·저항 운동 안전 지침, 그리고 개인별 치료 효과를 보장하지 않는다는 한계를 분리해 보여 준다. 이 구조는 운동 백과사전의 유용성을 유지하면서 근거의 범위를 과장하지 않도록 한다.

## 이후 우선순위

직접 연구 또는 전문 교육 자료를 각 대표 운동군에 더 촘촘히 연결하고, 대표 100종의 단계형 시각 가이드를 확대하는 것이 다음 콘텐츠 품질 우선순위다. 정적 개인용 원칙을 유지한다면, 기기 이동은 자동 계정 동기화보다 기존 JSON 백업·가져오기를 개선하는 방식이 적합하다.
