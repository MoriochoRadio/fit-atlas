# 비접촉 라켓·격투 입문 드릴의 적용 범위

## 설계 원칙

이 확장 묶음은 **혼자 수행하는 비접촉·저충격 입문 드릴**로 한정한다. 상대와의 대련, 스파링, 타격 대상 접촉, 강한 점프·피벗, 빠른 방향 전환 경쟁은 포함하지 않는다. 각 종목은 라켓 없이 수행 가능한 준비 자세·작은 발놀림·회복 위치 재설정, 또는 접촉 없는 가드·스텝·호흡 드릴처럼 독립적인 기술 학습 목적이 명확한 항목만 수록한다.

| 범주 | 포함 | 제외 |
|---|---|---|
| 라켓 입문 | 준비 자세, 분할 스텝, 짧은 셔플, 섀도 스윙, 회복 위치 | 공을 치는 경쟁 훈련, 전력 질주, 급정지·점프 전환 |
| 격투 입문 | 비접촉 가드, 짧은 스텝, 천천한 섀도 동작, 호흡·균형 | 대련, 스파링, 미트·샌드백 타격, 상대·물체를 향한 접촉 |
| 공간·장비 | 미끄럽지 않은 평평한 바닥, 주변 장애물 제거, 선택적 가벼운 라켓·빈손 | 혼잡한 공간, 불안정한 신발, 손상된 장비, 타인 근처의 스윙 |

## 일반 안전 경계

강도는 대화가 가능한 수준에서 시작하고, 새로운 발·무릎·고관절 통증, 저림, 어지러움, 비정상적 숨참, 균형 상실, 또는 외상 뒤 불편이 있으면 즉시 중단한다. 이 앱의 항목은 대회 기술 교육이나 무술 지도, 충격 노출에 대한 준비를 대체하지 않는다. 특히 대련·스파링·타격 기술은 인증된 코치와 적절한 보호 환경에서 별도로 지도받아야 한다.

CDC는 성인 신체 활동을 작은 단위로 나누어 수행할 수 있으며, 더 움직이고 덜 앉는 일반 원칙을 제시한다.[1] 이 원칙은 본 확장의 **짧고 저강도인 입문 세션 구조**에만 적용하며, 라켓·격투 기술의 임상적 효과 또는 충격 훈련의 안전성을 보증하는 근거로 사용하지 않는다. ITF Academy는 입문 테니스 코칭 과정과 코치 자료의 접근 경로를 제공한다.[2] 실제 기술 지도는 이러한 종목별 코치 교육 체계 및 지역 공인 지도 환경을 우선한다.
