# Fit Atlas 디자인 재구성 방향

## 선택한 방향

Fit Atlas는 과도한 스포츠 캠페인 화면이 아니라, 매일의 운동을 고르고 기록하는 **차분한 개인 트레이닝 워크스페이스**로 재구성한다. 배경은 밝은 쿨 그레이, 핵심 행동은 단일 인디고, 회복·경고 상태는 제한된 의미 색상으로 분리한다. 정보는 넓은 여백과 둥근 표면 안에 정리하며, 장식보다 다음 행동과 현재 상태를 우선한다.

## 적용 원칙

| 요소 | 적용 원칙 |
| --- | --- |
| 색상 | 기본 표면은 백색·쿨 그레이, 핵심 행동과 선택 상태만 인디고로 표시한다. |
| 서체 | `Noto Sans KR`로 제목과 본문을 통일하고, `IBM Plex Mono`는 짧은 라벨·수치에만 사용한다. |
| 표면 | 카드에는 16–24px 반경, 미세한 테두리와 얕은 그림자를 적용한다. |
| 행동 | 기본·보조·텍스트 행동을 명확히 나누고, 선택 상태는 색상과 경계 모두로 구분한다. |
| 모션 | 스크롤·표면 전환은 짧고 절제하며, 감소된 모션 환경에서는 즉시 전환한다. |

## 검토 결과

데스크톱 첫 화면과 390px 모바일 첫 화면에서 새 색상·타이포그래피·버튼 체계가 적용됨을 확인했다. 모바일에서는 하단 빠른 이동 바가 유지되므로, 이후 섹션은 마지막 행동 영역에 충분한 하단 여백을 보장해야 한다. 다음 구현 단계에서는 운동 탐색, 세션 설계, 회복, 분석 및 모달 세부 표면을 이 원칙으로 일관되게 정리한다.

해시 주소 기반 정적 캡처는 첫 화면 위치를 유지하므로, 탐색·기록·바디 맵의 세부 화면은 이후 브라우저에서 실제 스크롤 이동을 통해 별도로 확인한다.

팔레트 통합 후의 전체 페이지 검토에서는 웜 화이트 바탕, 딥 잉크 패널, 라임 신호가 반복되며 이전의 그린·블루·베이지 혼합 인상이 크게 줄어든 것을 확인했다. 딥 잉크 패널은 개인화 추천·주간 계획·개인 최고 기록처럼 집중이 필요한 정보에만 유지해 긴 화면에서 장면 전환 역할을 하도록 했다.

사진 없는 히어로에서는 운동선수 이미지 대신 좌표 격자, 궤적, 세 개의 경로 노드와 실제 현재 세션 정보를 사용한다. 데스크톱과 390px 모바일 검토에서 본문·시작 행동·세션 요약이 서로 겹치지 않고, 사진 없이도 아틀라스·움직임 계획의 맥락이 유지되는 것을 확인했다.

동적 아틀라스에서는 네 가지 색상 테마를 작은 스와치 제어로 제공하고, 선택 결과가 지도·노드·세션 카드의 신호 색상에 반영된다. 데스크톱과 390px 모바일 검토에서 제어부가 지도 안에서 과도하게 튀지 않으면서도 충분히 구분되며, 세션 목표별 궤적 상태를 담을 넓은 패널 면적을 확보했다.

테마 선택과 세션 경로 변경에는 짧은 신호색 확산, 패널 리프레시, 경로 재생, 순차 노드 반응을 추가했다. 정지 화면 검토에서도 제어부·통계 카드·세션 카드가 서로 겹치지 않았고, 모바일에서는 정보 카드를 하단 빠른 탐색 바 위에 안정적으로 유지했다. 감소된 모션 환경에서는 전역 모션 축소 규칙에 따라 즉시 전환된다.

조작형 아틀라스에서는 각 경로 노드를 실제 세션 블록의 편집 진입점으로 바꾸고, 테마 제어 아래에 느림·보통·빠름 재생 속도를 배치했다. 이번 주 완료율과 기록 수에 따라 준비·활성·고밀도 상태를 구분해 배경 입자 수와 신호 강도를 바꾼다. 데스크톱과 390px 모바일 검토에서 새 제어부가 통계·세션 카드와 겹치지 않았고, 노드의 큰 원형 표면을 터치 진입점으로 유지했다.

메인 간결화에서는 히어로의 설명문·로컬 저장 안내·하단 보조 문구와 아틀라스 안의 장식 통계를 제거했다. 현재는 한 줄 질문과 두 개의 행동만 남기고, 바로 아래에 실제 완료율·기록 수·신호 상태를 보여 주는 주간 아틀라스 리포트를 배치했다. 데스크톱과 390px 모바일 검토에서 제목·세션 카드·테마 제어의 대비를 유지하면서 이전보다 훨씬 짧은 시선 흐름을 확인했다.

주간 리포트 확장에서는 월~일별 계획·완료 수를 두 막대로 비교하는 미니 차트를 앞에 배치하고, 같은 패널에서 전신·근력·심폐 목표를 즉시 변경하게 했다. 완료율·기록 수·컨디션 신호를 해석한 다음 운동 방향은 한 줄 피드백으로 하단에 고정했다. 데스크톱과 390px 모바일 검토에서 차트의 요일·수치·목표 버튼이 같은 시선 흐름 안에 유지되는 것을 확인했다.

상호작용 피드백은 모든 주요 버튼·링크에 짧은 상승과 눌림을 적용하고, 카드·빠른 시작·필터에는 가벼운 부양을 부여하는 방식으로 통일했다. 선택 항목은 작은 확정 반동, 완료 체크는 회전 없는 체크 반동과 신호 그림자, 아틀라스 노드·미니 차트는 목표별 보상 모션을 사용한다. 데스크톱·390px 모바일 정지 화면에서 조작 표면과 하단 빠른 이동 바의 배치가 깨지지 않았고, 감소된 모션 환경에서는 애니메이션과 전환을 일괄 제거한다.

3D 인체 탐색기는 외부 이미지 대신 코드 기반 SVG·그라디언트·투시 변환으로 구성해 정적 배포 크기를 보존한다. 해시 기반 정적 캡처는 첫 화면에 머물렀고 연결된 개인 브라우저는 개발 호스트 허용 목록 제한으로 직접 확인하지 못했으므로, 컴포넌트 회귀와 전체 페이지 렌더링으로 구조를 확인한 뒤 최종 수동 검토를 보완한다.

확장한 근육 탐색기는 좌우 드래그 회전, 다중 부위 누적 선택, 선택 조합의 복합 운동 필터, 운동 상세 주동근(코랄)·협응근(블루) 표시를 단일 SVG 모델에 유지한다. 모델은 지연 로드하므로 첫 화면 번들에 포함되지 않으며, 전체 페이지 렌더링에서 기존 섹션의 카드 리듬과 충돌하지 않는 구조를 확인했다.
